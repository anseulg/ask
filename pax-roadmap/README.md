# PAX 로드맵

트랙별 과제의 상태·진행률·착수일/목표일/완료일을 한눈에 보고, 팀이 함께 과제를 추가·수정·삭제하는 로드맵 보드입니다.
Astryx 디자인 시스템(`dashboard-progress` 템플릿)으로 만들었습니다.

- 게시본: https://claude.ai/artifact/RYtEJqjz1qn2fCWboR4c5X
- 데이터: 게시된 페이지의 공유 저장소(`tracks`, `tasks` 컬렉션). 로컬 실행 시에는 예시 데이터로 동작하며 저장되지 않습니다.

```bash
npm install
npm run dev        # 로컬 미리보기
npm run artifact   # 단일 HTML(artifact.html) 생성 → Artifact로 게시
```
