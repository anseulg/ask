데이터 없으면 0 처리, 카테고리별 경쟁사 소스 변경, 가중치 자동 재분배 로직 포함

1. 데이터 스키마 — 6대축 입력값
각 축은 자사값(internal)과 외부값(external) 쌍으로 구성. 없으면 null로 입력, 엔진이 0으로 처리.
// 상품 1건의 원시 데이터 구조 interface ProductGPSInput { product_id: string category: '마트' | '패션' | '뷰티' | '리빙' | '가전디지털' | '기타' // 6대축 — 각 축마다 internal / external // null = 데이터 없음 → 엔진이 0으로 처리 price: { internal: number | null // 자사 판매가 external: number | null // 경쟁사 최저가 (PCI 산출용) } deal: { internal: number | null // 구좌 점수 (0~100) external: number | null // 경쟁사 베스트랭킹 위치 } momentum: { internal: number | null // MoM 변화율 (%) external: number | null // 소셜/트렌드 지수 (없을 수 있음) } metric: { internal: number | null // CVR, CTR, 검색순위 external: number | null // 경쟁사 검색 순위 (없을 수 있음) } review: { internal: number | null // 평점, 리뷰수 external: number | null // 경쟁사 평점, 리뷰수 } delivery: { internal: number | null // 배송 유형 (익일/일반/등) external: number | null // 경쟁사 배송 유형 } }

3. 데이터 없음(null) → 0 처리 및 가중치 재분배
핵심 로직: 데이터가 null인 축은 Gap 점수 0으로 처리하고, 해당 축의 가중치를 나머지 축에 비례 재분배

// 데이터 null 처리 엔진 function processAxis(axis, internal, external, category) { // CASE 1: 양쪽 모두 null if (internal === null && external === null) { return { gap: 0, weight: 0, status: 'NO_DATA' } } // CASE 2: 자사 데이터만 없음 → 카테고리 평균으로 대체 if (internal === null) { internal = getCategoryAvg(axis, category) weightMultiplier = 0.7 // 신뢰도 감소 status = 'ESTIMATED_INTERNAL' } // CASE 3: 외부 데이터만 없음 → 자사 데이터만으로 산출 if (external === null) { gap = calcGapInternalOnly(internal, axis, category) weightMultiplier = 0.7 // 신뢰도 감소 status = 'INTERNAL_ONLY' } // CASE 4: 양쪽 있음 → 정상 Gap 산출 else { gap = calcGap(internal, external, axis) weightMultiplier = 1.0 status = 'FULL_DATA' } return { gap, weight: finalWeight(axis) * weightMultiplier, status } } // 가중치 재분배 function redistributeWeights(axisResults[]) { const activeAxes = axisResults.filter(a => a.status !== 'NO_DATA') const totalWeight = sum(activeAxes.map(a => a.weight)) // 활성 축들의 가중치를 100%로 정규화 activeAxes.forEach(a => { a.normalizedWeight = (a.weight / totalWeight) * 100 }) // 최종 GPS = ∑(gap × normalizedWeight / 100) return activeAxes }
4. 시뮬레이터 — 카테고리/데이터 유무에 따른 가중치 변화
카테고리를 선택하고 축별 자사/외부 데이터를 각각 ON/OFF 제어해서 가중치 재분배 결과를 확인. 자사만 있으면 ×0.7, 외부만 있으면 ×0.5 감산.

6. 예외 케이스 — 데이터 부재 시나리오
CRITICAL 전축 데이터 없음 (6축 모두 null)
상황: 신규 입점 직후, 아직 아무 데이터 없음
처리: GPS 산출 불가 → “PENDING” 상태로 분류. 티어 미부여.
자동: 7일 후 자동 재산출 트리거. 여전히 전축 null이면 C등급 강제 배정.
WARNING 외부 데이터만 전체 없음 (경쟁사 매핑 불가)
상황: 특화 카테고리에서 경쟁사 데이터 수집 불가 (예: 니치 카테고리)
처리: 6축 모두 internal 데이터만으로 산출. 가중치 전부 ×0.7 적용.
Gap 산출: 경쟁사 없이 카테고리 평균 대비로 Gap 추정
표시: 대시보드에 “외부 데이터 부재” 배지 노출
INFO C커머스 데이터 특수 처리
상황: 알리/테무는 가격만 비교 가능, 리뷰/배송/딜 데이터 없음
처리: 가격축에 가중치 집중(40%+). 나머지 축은 자사 데이터만으로 산출.
특수: PCI 산출 시 C커머스 최저가가 시장가 아래로 떨어질 수 있음. “대체재 비교”로 표시 (직접 경쟁 아님)
RULE 최소 유효축 규칙
규칙: 최소 2축 이상 데이터가 있어야 GPS 산출 유효
1축만 있을 때: 해당 축 단독 판단 → 티어 불가, PENDING 처리
이유: 1축만으로는 종합 경쟁력 판단이 불가능. 오판 위험.
예외: AUTO-S(미입점)는 데이터 없어도 조건 없이 S 부여 (유효축 규칙 무시)
LOGIC 카테고리별 특화 경쟁사 우선순위
경쟁사 외부값 결정 우선순위:
1순위: 카테고리 특화 경쟁사 (마트→컬리, 뷰티→올리브영, 패션→무신사 등)
2순위: 공통 경쟁사 중 최저가 제공자 (네이버 > 쿠팡 > 지마켓)
3순위: SSG/롯데온 (브랜드/프리미엄 상품만)

외부값 산출 방식:
- 경쟁사 1사만 있을 때: 해당 경쟁사 값 직접 사용
- 경쟁사 2사 이상: 최저값 기준 (가격), 최고값 기준 (리뷰/배송), 평균 (딜/모멘텀/지표)
