Essential GPS Logic Spec v1.0

6대축 기반 3 Gap 진단 & 티어 배정 · SLA 프로세스

외부 10개 사이트 크롤링 + 내부 데이터를 6대축으로 분석 → 셀렉션/구색/가격 Gap 진단 → 티어 배정 → SLA 관리까지의 전체 프로세스

1. 6대축 분석 프레임워크 & 티어 배정
6대축 데이터로 3가지 Gap을 진단합니다. ① 셀렉션 Gap → AUTO-S(무조건 S등급), ② 구색 Gap → 보정 A등급, ③ 가격 Gap → 아래 6축 종합 점수로 S/A/B/C 배정. 탭을 클릭해서 비교하세요.
■ 기본 가중치 — 가격 Gap 판정 시 6축 종합 점수 산출 기준
// 가격 Gap 판정용 기본 GPS 산출식 (셀렉션/구색 Gap 필터링 후 적용)
GPS = ∑(축별_점수 × 기본_가중치)
    = 가격(25%) + 딜(20%) + 모멘텀(15%) + 지표(15%) + 리뷰(15%) + 배송(10%)
■ S등급 — 24h SLA / 가격·딜실적 급등, 리뷰·배송 약화
// S등급 (가격 Gap 판정): 금전적 손실이 발생중인 축에 집중
GPS_S = 가격(35%) + 딜(25%) + 모멘텀(15%) + 지표(10%) + 리뷰(10%) + 배송(5%)
// 가격 +10p, 딜 +5p → 리뷰 -5p, 배송 -5p, 지표 -5p
■ A등급 — 7d SLA / 가격·딜 소폭 상향, 모멘텀 강화
// A등급: 구조적 개선 + 모멘텀 포착
GPS_A = 가격(28%) + 딜(22%) + 모멘텀(18%) + 지표(14%) + 리뷰(12%) + 배송(6%)
// 모멘텀 +3p → 리뷰 -3p (성장세 판단 강화)
■ B등급 — 14d SLA / 검색 중심, 지표·리뷰 강화
// B등급: SEO/검색 부스팅 → 지표·리뷰 가중치 상승
GPS_B = 가격(20%) + 딜(15%) + 모멘텀(12%) + 지표(22%) + 리뷰(21%) + 배송(10%)
// 지표 +7p, 리뷰 +6p → 가격 -5p, 딜 -5p, 모멘텀 -3p
■ C등급 — 30d SLA / 균형 배분, 전체 관찰
// C등급: 모니터링 → 균등 배분으로 전체 축 관찰
GPS_C = 가격(18%) + 딜(17%) + 모멘텀(17%) + 지표(17%) + 리뷰(17%) + 배송(14%)
// 거의 균등. 특정 축 이상 징후 감지 목적
2. 강제 오버라이드 규칙
셀렉션 Gap(AUTO-S) · 구색 Gap · 가격 Gap(PRICE-X) 등 6대축 분석에서 감지된 조건 충족 시 무조건 S등급 승격
🚨
AUTO-S — 셀렉션 Gap 미입점 판정
6대축 데이터 분석으로 셀렉션 Gap 감지: 외부에서 판매중인데 자사에 없는 상품. GPS 점수 산출 자체가 불가능(자사 데이터 없음)하므로 무조건 S등급 부여.
IF 자사_상품_존재 = FALSE → FORCE S등급
가중치 적용: 가격(0%) 딜(0%) 모멘텀(0%) 지표(0%) 리뷰(0%) 배송(0%) → 외부 경쟁력 지수(ECI)만으로 우선순위 결정
💰
PRICE-X — 가격 Gap 긴급 (가격역전)
6대축 가격축 분석에서 감지: 경쟁사 대비 가격경쟁력지수(PCI)가 130 이상. 고객이 이탈중인 상황.
IF PCI ≥ 130 → FORCE S등급 (가격축 가중치 50%로 강제 적용)
가중치 오버라이드: 가격(50%) 딜(20%) 모멘텀(10%) 지표(10%) 리뷰(5%) 배송(5%)
🔥
SURGE — 바이럴 급등
모멘텀 축 급등 변동(MoM ≥ 300% 또는 소셜 역주행 감지). 타이밍 유효기간 48h.
IF 모멘텀_MoM ≥ 300% OR 소셜바이럴 = TRUE → FORCE S등급
가중치 오버라이드: 가격(15%) 딜(15%) 모멘텀(40%) 지표(15%) 리뷰(10%) 배송(5%)
3. S등급 15개 슬롯 배분 로직
미입점이 15개 초과 시, 트리거 유형별 슬롯 우선 확보 → 내부 GMV 소팅
슬롯 배분 시뮬레이션 (예시: 후보 47개 중 15개 선정)
PRICE-X 가격역전 (최우선)
SURGE 바이럴 (타이밍 한정)
AUTO-S 미입점 (나머지)
// 슬롯 배분 알고리즘
1. PRICE-X 슬롯 = min(5, count(PRICE-X)) // 최대 5개 고정
2. SURGE 슬롯  = min(2, count(SURGE))   // 최대 2개 고정
3. AUTO-S 슬롯 = 15 - PRICE-X슬롯 - SURGE슬롯 // 나머지 전부
4. 각 유형 내 소팅: 기회손실_GMV × 전환확률 내림차순
5. 잔여 후보 → 다음 사이클 큐에 자동 이월
4. 예외 케이스 처리
기본 로직으로 처리 불가능한 상황들의 예외 규칙
CRITICAL단일축 크리티컬 — 강제 티어 범프
▶
조건: 어느 한 축의 Gap이 90점 이상(가격 PCI ≥ 150 또는 딜실적 구좌 ≤ 20)
처리: 해당 축의 가중치를 +15%p 강제 상향, 나머지 축에서 비례배분 차감
예시: 가격 PCI 155 → S등급 가중치가 35% → 50%, 리뷰 10% → 5%, 배송 5% → 0%
결과: 해당 축의 액션 아이템이 자동으로 최상단 노출
CRITICAL복합 오버라이드 충돌 — PRICE-X + SURGE 동시
▶
조건: 한 상품이 PRICE-X와 SURGE 동시 충족 (가격역전 + 바이럴)
처리: PRICE-X 우선. 가격 문제가 바이럴보다 직접적 손실이 크기 때문.
가중치: 가격(45%) + 모멘텀(25%) + 딜(15%) + 지표(10%) + 리뷰(3%) + 배송(2%)
슬롯: PRICE-X 슬롯에서 차감 (중복카운트 방지)
WARNING데이터 부족 — 신규상품 7일 미만
▶
조건: 입점 7일 미만으로 딜실적·모멘텀·리뷰 데이터 부족
처리: 데이터 있는 축만 가중치 적용, 부족 축은 카테고리 평균값으로 대체
예시: 입점 3일차. 가격(35%) + 배송(15%) 만 실제 데이터, 나머지 4축은 카테고리 평균으로 50% 배분
주의: 7일 경과 후 자동 재산출 트리거 발동 (티어 변동 가능성)
WARNING시즈널 가중치 시프트
▶
조건: 대형 행사 기간(11절, 설날, 추석 등) D-14 ~ D+3 구간
처리: 모멘텀 가중치 +8%p, 가격 가중치 +5%p (시즈널 가격경쟁 격화)
차감: 배송(-3%p), 리뷰(-5%p), 지표(-5%p)
이유: 시즈널에는 타이밍과 가격이 거의 모든 것을 결정. 리뷰·지표는 시즈널 후 자연복귀
INFO카테고리 방향성 오버라이드
▶
조건: 조직장이 카테고리 방향성을 “성장” 또는 “효율”로 설정
성장 모드: 모멘텀 +5%p, 딜실적 +3%p → 배송 -5%p, 지표 -3%p
효율 모드: 가격 +5%p, 지표/CVR +5%p → 모멘텀 -5%p, 딜실적 -5%p
유용: 같은 S등급 상품이라도 조직장 의도에 따라 액션 우선순위 달라짐
INFO동일 상품 멀티카테고리 중복
▶
조건: 한 상품이 여러 MD 카테고리에 걸칠 때 (예: 모니터 = 가전 + 주변기기)
처리: 가장 높은 티어의 MD에게 우선 배정. 나머지 MD에게는 “타 MD 액션 진행중” 표시
기준: S > A > B > C 순. 동일 티어면 GPS 점수 높은 카테고리 우선
5. SLA 미처리 에스컬레이션 프로세스
MD 미액션 시 시간대별 자동 에스컬레이션. S등급 기준 (다른 티어는 비례 확장)
T+0h — 태스크 배정
상품 카드 발급 + MD 알림
GPS 산출 완료 → 티어 판정 → MD 대시보드에 상품 카드 노출
상태값: ASSIGNED / 카운트다운 시작
MD에게 알림톡 발송 (푸시 + 슬랙 + 이메일)
T+6h — 1차 리마인더
자동 리마인더 발송
상태값이 여전히 ASSIGNED이면 자동 리마인더
“[S등급] OOO 상품 미처리 — 18시간 남음”
상태값: REMINDED
T+18h — 오렌지 알럿
팀장에게 동시 알림 + 대시보드 경고 표시
MD + 팀장 동시 알림. 대시보드에 오렌지 경고 배지 노출
“⚠️ 6시간 남음 — SLA 위반 예정”
상태값: ESCALATED_L1
팀장 액션: MD에게 직접 확인 또는 재배정 결정
T+24h — SLA 브리치
SLA 위반 확정 + 자동 페널티 부과
상태값: BREACHED

자동 처리 3건:
① GPS 점수 페널티: 해당 상품 Gap에 +10점 강제 가산. 티어 상승 가능성 ▲
② 자동 재배정: 같은 카테고리 내 대체 가능한 부MD 또는 팀장에게 자동 전이
③ 이력 기록: MD 성과 대시보드에 SLA 브리치 카운트 누적
T+48h — 본부장 에스컬레이션
본부장급 알림 + 상품 동결 검토
상태값: ESCALATED_L2
본부장에게 주간 리포트에 포함. 미처리 사유 분석
극단 결정: 상품 동결 해제 또는 카테고리 재편성 검토
6. 티어별 SLA 비교 매트릭스
각 티어별 시간 임계값과 에스컬레이션 단계 비교
SLA1차 리마인더팀장 알림SLA 브리치본부장 에스컬레이션페널티
S 즉시실행 24h T+6h T+18h T+24h T+48h Gap +10점
A 주간과제 7d T+2d T+5d T+7d T+10d Gap +7점
B 검색부스팅 14d T+5d T+10d T+14d T+21d Gap +5점
C 모니터링 30d T+10d T+20d T+30d — Gap +3점
7. MD 액션 후 상태값 전이
MD가 액션했을 때의 처리 프로세스와 상태값 변화
// MD 액션 완료 시 상태 전이

CASE 1: 정상 처리 (SLA 내)
  상태: ASSIGNED → RESOLVED
  처리: 해당 슬롯 비움 → 큐에서 다음 상품 자동 승격
  기록: 처리시간, 액션내용, 결과값 저장
  GPS 재산출: 다음 사이클에서 반영

CASE 2: 지연 처리 (SLA 초과)
  상태: BREACHED → RESOLVED_LATE
  처리: 슬롯 비움 + 페널티는 유지
  페널티: Gap +10점은 다음 사이클까지 유지 (즉시 해제 안됨)
  기록: SLA 초과 시간, 초과 사유 함께 저장

CASE 3: 미처리 자동 재배정
  상태: BREACHED → REASSIGNED
  처리: 원래 MD에서 제거 → 부MD/팀장에게 자동 전이
  SLA: 새로운 24h SLA 시작 (리셋 아님)
  기록: 재배정 사유, 원래 MD 이력 기록에 반영
8. 큐 순환 로직
15개 처리 완료 시 다음 상품 자동 승격 규칙
// 큐 순환 알고리즘

매 상품 RESOLVED 시:
  1. 빠진 슬롯의 트리거 유형 확인
  2. 대기큐에서 동일 트리거 유형 최상위 승격
  3. 대기큐에도 동일 유형 없으면 → 기회손실GMV 내림차순으로 승격
  4. 슬롯 빌 때마다 승격 (배치적 승격 아님)

매일 09:00 전체 재산출:
  1. 외부 10개 사이트 크롤링 + 내부 데이터 수집
  2. 6대축 분석 실행 (가격·딜·모멘텀·지표·리뷰·배송)
  3. 셀렉션 Gap → 구색 Gap → 가격 Gap 순서로 3 Gap 진단 → 티어 재판정
  4. 어제 A였던 상품이 오늘 S로 바뀔 수 있음
  5. 새 S등급 발생 시 → 기존 큐에 우선 삽입(기존 대기자 밀림 아님)
