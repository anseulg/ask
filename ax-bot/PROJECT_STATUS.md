# ax-bot — 작업 현황 (Project Status)

> 전사 효율화 봇 에이전트. 현재 **개인 검증(private validation)** 단계.
> 마지막 업데이트: 2026-09-03

## 1. 목표 (What)

사람이 도구를 찾아가지 않고, **슬랙에서 묻기만 하면 봇이 답한다.** AX TF로 반복해서 들어오는 조회성 질문을 봇이 대신 받아 처리하는 것이 목표다.

레버리지가 큰 세 가지 유형:

| 유형 | 설명 | 단계 |
|---|---|---|
| ① 조회 대행 | "그거 어디 있어요? 지금 상태 어때요?"를 없앤다 | **1단계 (지금)** |
| ② 초안 생성 | 주간보고·과제등록·회의록 등 반복 문서의 초안 | 2단계 |
| ③ 감시·알림 | 목표일 경과·정합성 깨짐 등을 봇이 대신 감시 | 3단계 |

## 2. 확산 순서 (좁게 시작)

1. **AX TF 내부** (관리자 16명) — 로드맵 조회·주간보고 초안
2. **현업 담당 조직** — "내 과제 상태" 조회 + 과제 등록 요청
3. **전사** — 위키·정산 매뉴얼 등 (사내 문서 검색 pixi가 주인공)

> 순서를 뒤집으면 실패한다. 전사부터 열면 질문이 넓어져 답이 부정확해지고, 한 번 틀리면 사람들이 다시 안 쓴다.

**현재 방침:** 우선 **나 혼자 쓰며 검증 → 그다음 보급.** 검증 단계에선 조회(①), 그중에서도 **로드맵 조회 하나**만 제대로 만든다.

## 3. 아키텍처 (How)

```
슬랙(질문) → Bolt(Socket Mode) → Claude 에이전트(도구 판단) → 도구 실행 → 근거 링크 붙은 답변
                                        │
                                        ├─ [1단계] 로드맵 조회 (roadmap_kv)
                                        ├─ [2단계] Jira 조회 / 과제 등록 초안
                                        └─ [3단계] 위키·정산 매뉴얼 검색(pixi)
```

- **슬랙 계층:** Slack Bolt, **Socket Mode** (공개 서버·URL 불필요)
- **두뇌:** Claude `claude-sonnet-5` (`@anthropic-ai/sdk` ^0.122.0), tool-use 루프
- **도구를 하나씩 붙이는 구조:** 1단계는 `lookup_roadmap` 하나. 잘 돌면 Jira·위키는 같은 틀에 도구만 추가.

## 4. 가드레일 (봇이 죽는 이유를 미리 막기)

| 실패 원인 | 방어 (코드/프롬프트에 반영) |
|---|---|
| 틀린 답을 자신 있게 한다 | 근거 링크를 항상 붙인다. 모르면 "모른다"고 한다 |
| 쓰기 사고 | **읽기 전용.** 생성은 초안→사람 확인→실행. 봇이 바로 저장하지 않는다 |
| 아무도 안 쓴다 | 기존 습관 자리(슬랙)에서 동작 |
| 느리다 | 3초 안에 "🔎 찾는 중이에요…" 즉답. 침묵이 가장 나쁘다 |
| 권한 사고 | 물어본 사람의 권한으로만 답한다 (보급 시 access-guard 로스터 재사용) |

## 5. 지금까지 구현된 것 (`ax-bot/`)

| 파일 | 내용 |
|---|---|
| `app.js` | Bolt Socket Mode. 멘션/DM 처리, "찾는 중" 3초 즉답, `ALLOWED_SLACK_USER_IDS` 개인 검증 잠금, 에러 처리 |
| `agent.js` | Claude tool-use 루프 + `lookup_roadmap` 도구, 가드레일 시스템 프롬프트, 무한루프 방지(최대 5회) |
| `roadmap.js` | 지금은 **더미 데이터 4건**. 실 `roadmap_kv` 쿼리 자리를 `mysql2` 참조 구현(주석)으로 준비 |
| `README.md` | 셋업·env·단계별 로드맵 |
| `.env.example` | 필요한 환경변수 목록 (비밀값 없음) |
| `.gitignore` | `node_modules/`, `.env` 무시 |

- 브랜치: `claude/slack-session-gnzcxs` / **PR #16**
- 모든 파일 `node --check` 통과, `.env`·`node_modules` 미포함

- 위치: **알바트로스(Albatross)** 안, `ax-tf-platform`의 DB (MariaDB, MaxScale 포트 6446)

## 7. 역할 분담

**Claude (코드):** 에이전트 코드, 도구 구현, 실 쿼리 작성(스키마 제공 시), 도구 추가(Jira·위키)

**사람 (권한·비밀값·네트워크·배포):**
- 슬랙 앱 생성 + 토큰 2개 발급 (`SLACK_BOT_TOKEN`, `SLACK_APP_TOKEN`)
- `ANTHROPIC_API_KEY` 발급 (+ 낮은 spend limit 권장)
- `.env` 작성 (+ 본인 슬랙 ID를 `ALLOWED_SLACK_USER_IDS`에)
- 사내망(172.28.x DB) 접근 가능한 환경에 배포 · 실행

> 참고: 이 원격 세션은 사내 DB에 못 닿고 `ax-tf-platform` 리포도 못 읽는다. 봇의 실제 실행·DB 연결은 사용자 터미널(`ax-tf-platform` 환경)에서 이뤄진다.

## 8. 비용 (추정, `claude-sonnet-5` 기준)

- 질문 1건당 약 **1~3센트** (입력 ~3~5k 토큰 + 출력 수백 토큰)
- **나 혼자 검증:** 월 몇 천 원 (거의 무시 가능)
- AX TF 16명: 월 수만 원대 / 전사: 수십만 원~ (이때 최적화 필요)
- 절감 레버: **프롬프트 캐싱**(반복 입력 ~90%↓), **모델 티어링**(단순 조회는 저가 모델), 짧은 답변
