예정
통합 랭킹 산출 절차
① 11번가에 없는 경쟁사 인기상품만 추출 → ② 통합 랭킹 산정 → ③ 인기 순 정렬 → 입점 우선순위 제시
② 현재 1안 — 날짜별로 채널·카테고리별 베스트 순위 1위만 가져와 통합
점수식 (안) — 0~100 정규화 → 품질·세그 가중 → 등급 S/A/B/C
현재 1안네이버 베스트 순위 · 순위 0~100 정규화 · 구매순 > 클릭순 적용 (다채널 통합·가중치는 3차)
안 · 품질× 리뷰수 (로그 정규화 · 수집 O) · × 별점 (하한 게이트 · 별점 확인 필요)
안 · 세그전체 × 0.7 + 타깃 세그(성별×연령) × 0.3 · 또는 세그 필터 (수집 O)
변화 감지상승/하락/신규 = 전일 스냅샷 대비 점수 변화 (2차)
↳
세부안 — 통합 등급(S / A / B / C) 산정 기준 (B안)
채널마다 "베스트"의 기준이 다르므로, 원시 순위를 0~100 통합 점수로 정규화한 뒤 품질·세그 가중을 곱해 등급을 산출한다.
STEP 1 — 기본 점수 (Base Score)
채널 내 순위를 0~100으로 정규화
base = (1 − rank / total) × 100
네이버: 구매순 가중 > 클릭순 / 일반 채널: Best 랭킹 단일
STEP 2 — 품질 가중 (Quality Gate)
리뷰수 log₁₀(리뷰수 + 1) 정규화 → 0~1 계수
리뷰 없는 채널(카카오·GS) → 계수 1.0 (패널티 없음, 데이터 결손 처리)
별점 하한 게이트: 별점 < 3.5 → 1등급 하향
별점 미제공 채널 → 게이트 미적용
STEP 3 — 세그먼트 가중 (네이버 · 무신사 한정)
final = base × 0.7 + seg_base × 0.3
세그 데이터 없는 8개 채널 → 전체(seg_base = base)로 대체, 실질 가중 없음
STEP 4 — 등급 스코어링 기준
등급 점수 범위 의미
S 85 ~ 카테고리 최상위 경쟁력 — 즉시 입점 검토 대상
A 65 ~ 84 경쟁력 양호 — 입점 우선 추천 풀
B 40 ~ 64 중위권 — 카테·셀러 조건 맞으면 선별 검토
C ~ 39 하위권 — 모니터링만, 입점 추천 제외
스코어링 기준은 초기 분포 확인 후 조정. 별점 게이트에 걸리면 최종 등급 1단계 하향 (S→A, A→B …)
STEP 5 — 다채널 중복 탐지 · 가중 (3차)
동일 상품이 여러 채널 베스트에 동시 노출되면 → 중복 탐지 후 가중 적용
탐지 상품명·브랜드·용량 매칭 키로 채널 간 동일 상품 식별 (매칭 로직 재활용)
가중 노출 채널 수에 따라 부스트 — boost = 1 + 0.1 × (채널수 − 1)
2개 채널 → ×1.1 / 3개 채널 → ×1.2 / 최대 ×1.5 캡
채택 중복 그룹 내 최고 점수 채널 1건만 채택, 나머지는 병합 처리
시뮬레이션 — 10개 채널 × 가상 상품 예시
각 채널 베스트 상위 상품 1건을 가정하고 STEP 1→4를 적용한 예시. 숫자는 설명용 가상치.
