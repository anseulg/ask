05 Gap Diagnosis
3단계 Gap 진단 — 없는 것부터 찾고, 있는 것을 고친다
외부 10개 사이트 + 내부 데이터를 매칭하여 상품을 진단합니다. 각 Gap은 판별 방식이 다릅니다.
1
셀렉션 Gap MVP
경쟁사에만 있고 우리에게 아예 없는 상품
판별: 외부 상품 매칭 실패 (있다/없다)
→ 베스트 순위 높을수록 우선 강제 S
→ 24h 내 셀러 영업 착수
2
구색 Gap MVP
상품은 있지만 카테고리별 구색이 빈약한 영역
판별: 판매0건·휴면·카테고리공백 감지
→ 우리 SKU 수가 부족한 영역 도출
→ 셀러 영업 + 상품 확대
3
가격 Gap MVP
양쪽 다 있는 상품의 경쟁력 차이 비교
판별: 6축 가중치 점수 (아래 표 참조)
→ 가격25 · 딜20 · 모멘텀15 · 지표15 · 리뷰15 · 배송10
→ 축별 개선 과제 도출
▼ 6대축 분석 프레임 — 3 Gap 전체를 관통하는 데이터

D딜 실적P220%자사 결제건수, 거래액외부 카테고리 평균구좌지수 = 거래액 / 구좌평균 × 100
부진
딜 실적 상세
카테고리 평균 대비 구좌 지수가 82로 하회. 프로모션 확대로 개선 가능.
M모멘텀P215%자사 D, D-1~7 거래액자사 과거 시계열모멘텀 = (D − D-1) / D-1
성장

C지표/CVRP215%자사 PV, 결제건수외부 카테고리 평균 CVRCVR = 결제건수 / PV
하회
CVR 상세
구매전환율이 카테고리 평균 대비 낮음. 상품 상세 페이지 개선 필요.
R리뷰MVP15%자사 평점, 리뷰수외부 경쟁사 평점Gap = (자사 − 외부) + 건수보정
우수
리뷰 상세
평점 4.7, 리뷰수 842건으로 경쟁사 대비 우수한 수준.
S배송P210%자사 배송타입, 배송비외부 타사 배송속도배송유형 + C2D 속도
익일

09 Flywheel
선순환 엔진 — 데이터가 쌓일수록 진단이 정확해진다
3 Gap 발굴 → 셀러 영입 → 혜택 → 가격 → 노출 → 거래·등급 판정을 순환합니다. 데이터 구축 범위가 넓어질수록 순환 속도와 정확도가 높아집니다.
STEP 1
발굴
10개+ 외부 사이트 횡단 정찰 → 11번가에 반드시 있어야 할 상품 도출

STEP 2
영입
S등급은 MD 직접 설득, A등급 이하는 셀링툴 자동 확보
셀러 입점 제안서를 자동 생성하고, MD가 직접 연락하여 영입을 진행합니다.
STEP 3
혜택
왜 11번가인가 구조화. 수수료·광고포인트·쿠폰 번들
셀러에게 11번가 입점의 경제적 이점을 구조화하여 제시합니다.
STEP 4
가격 정합
기준 이탈 가격을 MSO/SO가 시스템으로 교정. 수수료 5% 인하 레버
가격 비교 엔진이 경쟁사 대비 가격을 실시간으로 모니터링합니다.
