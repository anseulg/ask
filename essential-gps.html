Category Flow
카테고리별 실행 플로우 — MD가 6단계로 움직입니다
각 Phase를 클릭하면 상세 실행 내용이 펼쳐집니다.
Phase 1 · 시스템
자사 디스커버리 수집
BIDB 마트에서 카테고리별 결제건수, 거래액, 가격, 리뷰, 배송 데이터를 수집하여 현재 상태를 구조화합니다.
BIDB 마트자동 수집
Phase 2 · 시스템
외부 경쟁 데이터 수집
Albatross Crawling로 경쟁사 가격, 리뷰, SKU, 트렌드, 시즐성, 이슈상품을 수집. 카테고리별 기준선을 세웁니다.
Albatross Crawling10개 사이트 MVP
Phase 3 · 시스템
Gap 분석 & S/A/B/C 스코어링
자사 vs 외부 6축 비교 → Gap 산출 → 4단계 디시전 트리 → S/A/B/C 등급 자동 부여. 카테고리별 Task 리스트 초안 생성.
Scoring 엔진Task 자동 생성
Phase 4 · 조직장
카테고리 방향성 설정 & 가중치
시스템이 제공한 데이터를 확인하고 성장/효율 등 운영 방향을 입력. 가중치가 반영되어 Task 우선순위가 재조정됩니다.
방향성 입력가중치 설정
Phase 5 · 시스템 → MD
MD별 개인화 Task 배분
조직장 가중치 + 전사 행사 일정 + 과거 Reject 이력 반영하여 MD별 Task 배분. MD는 Accept/Reject 의사결정.
우선순위 배분Accept/Reject
Phase 6 · MD + 시스템
Task 실행 & 성과 트래킹
Task를 실행하고 수행 단계를 업데이트. 시스템이 Gap 변화·등급 변동을 자동 트래킹. Reject 사유와 성과가 Scoring 엔진 고도화에 피드백.
수행 업데이트Scoring 학습
Flywheel
선순환 엔진 — 여섯 단계가 스스로 가속합니다
Essential SKU 발굴에서 점화하여 셀러 영입 → 혜택 → 가격 → 노출 → 거래·등급 판정을 순환합니다. 각 단계를 클릭하면 상세 설명이 펼쳐집니다.
STEP 1
발굴
10개+ 외부 사이트 횡단 정찰 → 11번가에 반드시 있어야 할 상품 도출
Albatross Crawling가 경쟁사 TOP 판매 상품을 자동 수집. 카테고리별 필수 SKU 리스트를 생성합니다.
STEP 2
영입
S등급은 MD 직접 설득, A등급 이하는 셀링툴 자동 확보
셀러 입점 제안서를 자동 생성하고, MD가 직접 연락하여 영입을 진행합니다.
STEP 3
혜택
왜 11번가인가 구조화. 수수료·광고포인트·쿠폰 번들
셀러에게 11번가 입점의 경제적 이점을 구조화하여 제시합니다.
STEP 4
가격 정합
기준 이탈 가격을 MSO/SO가 시스템으로 교정. 수수료 5% 인하 레버
가격 비교 엔진이 경쟁사 대비 가격을 실시간으로 모니터링합니다.
STEP 5
노출
검색·홈·편성·다이나믹·광고·PCS 최적 채널 배치
등급에 따라 노출 채널을 자동으로 배치합니다.
STEP 6
거래 & 등급
거래 성과로 S/A/B/C 판정 → 다음 사이클 점화
거래 데이터가 Scoring 엔진에 피드백되어 등급이 재판정됩니다.
거래 성과가 등급을 결정하고, 더 정밀한 Essential SKU 재발굴과 더 가치 있는 셀러 영입으로 이어진다 — 엔진이 돌아갈수록 Selling Pool이 채워지고 거래가 커집니다
