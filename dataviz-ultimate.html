Gap Analysis
6대 축 Gap 분석 — 자사 vs 외부 비교
진단 축자사 데이터 (디스커버리)외부 데이터 (벤치마크)Gap 산출 로직신호등
가격자사정상가, 현재가외부경쟁사 최저가PCI = (자사 현재가 − 외부 최저가) / 외부 최저가우수 주의 열위
딜 실적자사결제건수, 결제거래액, 행구좌외부카테고리 평균 거래 규모구좌 지수 = 자사 거래액 / 구좌 평균 × 100우수 부진 미달
과거 딜 대비자사D, D-1, D-1~7 결제거래액자사자사 과거 실적 (시계열)모멘텀 = (D − D-1) / D-1성장 둔화 하락
지표자사PV, 결제건수, 결제순매출율외부카테고리 평균 전환율1차 CVR = 결제건수 / PV
2차: CTR · iCTR · sCTR (확보 후)		상위 하회 저조
리뷰자사평점, 리뷰수외부경쟁사 평점, 리뷰수Gap = (자사 평점 − 외부 평점) + 건수 차이 보정우수 보통 주의
배송자사배송타입, 배송비외부타사 배송 속도, 무료배송 비율배송유형 + C2D 속도 비교익일 2~3일 4일+
