Category Strategy
카테고리별 MD 전략 플로우
조직장이 카테고리 방향을 설정하고, 시스템이 자사·외부 데이터를 비교한 Gap 기반 Task를 생성하며, MD가 실행합니다.
Phase 1 · 시스템
자사 디스커버리 수집 — 카테고리별 현황 파악
BIDB 마트에서 카테고리별 결제건수, 거래액, 가격, 리뷰, 배송 데이터를 수집. 카테고리 단위로 현재 상태를 구조화합니다.
BIDB 마트자동 수집
Phase 2 · 시스템
외부 경쟁 데이터 수집 — 벤치마크 기준선
AX·Albatross로 경쟁사 가격, 리뷰, SKU, 트렌드, 시즌성, 이슈상품을 수집. 카테고리별 외부 기준선을 세웁니다.
AX · Albatross경쟁사 모니터링자동 수집
Phase 3 · 시스템
Gap 분석 & S/A/B/C 스코어링
자사 데이터 vs 외부 데이터를 6대 축에서 비교 → Gap 산출 → 종합 Score로 S/A/B/C 등급 자동 부여. 카테고리별 Task 리스트 초안 생성.
Scoring 엔진Task 자동 생성
Phase 4 · 조직장
카테고리 방향성 설정 & 가중치 반영
시스템이 제공한 자사·외부 데이터를 확인하고 성장/효율 등 운영 방향을 입력. 가중치가 반영되어 Task 우선순위가 재조정됩니다. 분기/월 1회 Monthly task 직접 설정.
방향성 입력가중치 설정Monthly task
Phase 5 · 시스템 → MD
MD별 개인화 Task 배분 & 확인
조직장 가중치 + 전사 행사 일정(월간/그랜드십일절/페스타) + 과거 Reject 이력(2개월 미노출) 반영하여 MD별 우선순위 Task 배분. MD는 적정성 판단 후 Accept/Reject.
우선순위 배분Accept/RejectReject 사유 입력
Phase 6 · MD + 시스템
Task 실행 & 성과 트래킹
정제된 Task를 실행하고 수행 단계를 업데이트. 시스템이 실적을 자동 트래킹하여 Gap 변화·등급 변동을 반영. Reject 사유와 성과가 Scoring 엔진 고도화에 피드백.
